Introdução ao JavaScript

O que é o JavaScript?

É uma linguagem de programação muito utilizada para criar aplicações interativas e sistemas de software.

Ele é o responsável por:

  • Responder a cliques
  • Validar formulários
  • Atualizar Conteúdos
  • Buscar dados de APIS
  • Controlar o comportamento da aplicação

IMPORTANTE: JavaScript não é Java. Apesar da semelhança nos nomes, são linguagens totalmente diferentes, com características e ecossistemas próprios.

Curiosidade: Foi criado em apenas 10 dias.

O que mais da pra fazer com JS

  • Frontend
    • Criar interfaces interativas
    • Menus
    • Validações
    • Filtros
    • Animações
    • Dashboards
    • Aplicações com React, Vue, Angular, Astro e etc.
  • Backend
    • Nodejs
    • Criar APIS REST
    • Autenticação
    • Processar requisições
    • Integrar com servições e com banco de dados
  • Mobile/Desktop
    • Criar aplicativos
    • React Native e Electron
